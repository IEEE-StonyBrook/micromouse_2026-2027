# Micromouse

The SBU IEEE Micromouse team's mice, the contests they race in, and the
firmware that drives them.

## Language

### Mice

**Mouse 1**:
The 2026–27 mouse built for APEC, with the suction fan fitted.
_Avoid_: APEC mouse, fan mouse

**Mouse 2**:
The 2026–27 mouse built for NYIT: the same build as Mouse 1 without the fan
motor and impeller.
_Avoid_: NYIT mouse, no-fan mouse

**Backup mouse**:
Last season's mouse, carried to a contest in case the race mouse fails.
_Avoid_: spare mouse, old mouse

### Maze

**Seam**:
A joint between two floor sheets, possibly taped over, that the mouse
drives across.
_Avoid_: bump

### Runs

**Competition mode**:
The firmware mode used at a contest: a staged sequence of exploration,
return and fast runs, started by gestures, with abort and resume.
_Avoid_: contest mode, race mode
